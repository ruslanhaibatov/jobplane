TAG 01 Profil & Unterlagen vorbereiten Heute ▼
  • ✓
    GitHub Profil aufräumen — README.md mit Kurzvorstellung
    Pinne deine 3 besten Repos oben an. Füge Beschreibungen und Topics hinzu.
  • ✓
    LinkedIn Profil aktualisieren — Profilbild, Headline, "Open to Work"
    Headline z.B.: "Junior Web Developer | React · Python · suche erste Stelle in DE"
  • ✓
    Lebenslauf (CV) auf Deutsch erstellen — 1 Seite, modernes Design
    Nutze Europass oder canva.com. Wichtig: Skills, Projekte, Sprachen (Deutsch-Level!)
  • ✓
    Alle aktuellen Projekte auf GitHub pushen — kein leeres Repo!
    README mit: Was ist es? Tech Stack. Screenshot/GIF. Live-Link wenn möglich.
  • ✓
    Liste der Skills zusammenstellen (Tech Stack)
    z.B.: JavaScript, React, Node.js, Python, SQL, Git — ehrlich bleiben!
Tipp: Dein GitHub ist dein Portfolio. Recruiter schauen dort zuerst. Selbst kleine Projekte wirken professionell mit gutem README.
TAG 02 Bewerbung schreiben (Template) Wichtig ▼
  • ✓
    Anschreiben (Bewerbungsschreiben) Template erstellen
    Auf Deutsch. Kurz: 3 Absätze. Warum du, warum die Firma, was du mitbringst.
  • ✓
    Englisches Cover Letter Template erstellen
    Viele Startups in DE suchen auf Englisch. Beide Versionen bereithalten.
  • ✓
    Kurzvorstellung (3-Satz "Pitch") formulieren
    Für E-Mails, LinkedIn-Nachrichten, Cold Outreach. Immer gleich, schnell einfügen.
  • ✓
    Professionelle E-Mail-Adresse prüfen
    Format: vorname.nachname@gmail.com — keine coolen Nicknames!
Tipp: Schreib nie eine Bewerbung ohne den Firmennamen anzupassen. Copy-paste ohne Änderung wird direkt aussortiert.
TAG 03 Stellen suchen & Liste aufbauen Kernarbeit ▼
  • ✓
    LinkedIn Jobs: "Junior Developer Germany" — 20+ Stellen speichern
    Filter: Entry Level, letzte 7 Tage. Remote-freundliche Firmen bevorzugen.
  • ✓
    Indeed.de / StepStone.de durchsuchen
    Suchbegriffe: "Junior Entwickler", "Junior Software Developer", "Werkstudent Entwicklung"
  • ✓
    Startups über German Startup Jobs & Jobspotting suchen
    jobs.lever.co, greenhouse.io — Startups haben lockerere Anforderungen für Juniors
  • ✓
    Tracking-Tabelle anlegen: Firma | Stelle | Status | Datum | Link
    Google Sheets reicht. Ohne Tracking verlierst du den Überblick.
  • ✓
    Ziel: 15–20 Firmen auf der Liste bis Tagesende
    Qualität > Quantität, aber in 7 Tagen brauchen wir Volumen.
Tipp: Bewirb dich auch bei Firmen, die "Junior" nicht explizit schreiben. Viele nehmen gute Kandidaten auch ohne Erfahrung wenn Motivation stimmt.
TAG 04 Erste Bewerbungen rausschicken (10 Stück) Aktiv ▼
  • ✓
    Top 10 Firmen aus Liste auswählen und Anschreiben anpassen
    Pro Firma: 5–10 Min Recherche. Was macht die Firma? Welche Technologien?
  • ✓
    Bewerbungen per E-Mail oder Bewerbungsportal einreichen
    Betreff: "Bewerbung als Junior Developer — [Dein Name]". Immer CV als PDF anhängen.
  • ✓
    Auf LinkedIn direkt bei Recruitern bewerben (Easy Apply)
    Easy Apply + kurze persönliche Nachricht an den Recruiter erhöht Chancen.
  • ✓
    Status in Tracking-Tabelle aktualisieren
TAG 05 Portfolio-Projekt vorzeigbar machen Portfolio ▼
  • ✓
    Aktuelles Hauptprojekt auf GitHub: sauberes README, Screenshots, Demo-Link
    Deploy auf Vercel / Netlify / Railway — kostenlos, 5 Minuten. Live-Demo > kein Demo.
  • ✓
    Projektzusammenfassung schreiben: Was? Warum? Welche Probleme gelöst?
    Kannst du in 2 Minuten erklären was das Projekt macht? Dann ist es bereit.
  • ✓
    GitHub-Link in CV und Bewerbungsunterlagen einfügen
  • ✓
    Optionale einfache Portfolio-Webseite (1 Seite HTML reicht)
    Name, Skills, 2-3 Projekte, Kontakt. GitHub Pages = kostenlos hosten.
Tipp: Recruiter schauen sich selten den Code an — aber einen funktionierenden Live-Link klicken sie immer. Deploy > schöner Code.
TAG 06 Weitere 10 Bewerbungen + Networking Aktiv ▼
  • ✓
    Zweite Runde Bewerbungen: 10 weitere Firmen
  • ✓
    LinkedIn: 5–10 Recruiter/Hiring Manager anschreiben (kein Copy-Paste!)
    Kurz: "Ich bin Junior Dev, suche erste Stelle in DE, hier ist mein GitHub [link]"
  • ✓
    Tech-Communities beitreten: Dev.to, Discord-Server, lokale Dev-Gruppen Meetup.com
    Viele Jobs werden nie öffentlich ausgeschrieben — Netzwerk ist entscheidend.
  • ✓
    Auf XING Profil anlegen — in DE noch relevant, besonders für traditionelle Firmen
  • ✓
    Vermittlungsagenturen kontaktieren: Hays, Gulp, Adecco IT
    Die suchen aktiv Kandidaten und schlagen dich Firmen vor. Kostenlos für dich.
TAG 07 Follow-Up + Letzte Bewerbungen Final Push ▼
  • ✓
    Follow-Up E-Mails an Bewerbungen von Tag 4 (wenn keine Antwort)
    "Ich wollte kurz nachfragen ob meine Bewerbung angekommen ist…" — höflich, kurz.
  • ✓
    Letzte offene Bewerbungen aus der Liste rausschicken
  • ✓
    Interview-Vorbereitung beginnen: 5 typische Tech-Fragen üben
    Arrays, Loops, OOP Grundlagen, Git-Workflow, ein persönliches Projekt erklären können.
  • ✓
    Gesamtstatus prüfen: Wie viele Bewerbungen? Antworten? Interviews?
Reminder: 7 Tage sind eng. Ziel ist nicht der perfekte Job — Ziel ist ein Interview. Der Rest folgt.

📧 Bewerbung per E-Mail (Deutsch)

Betreff: Bewerbung als Junior Softwareentwickler — [Dein Name]

Sehr geehrte Damen und Herren,

mit großem Interesse habe ich Ihre Stellenausschreibung für eine Junior-Entwicklerstelle gelesen. Als angehender Entwickler mit Kenntnissen in [Tech Stack, z.B. JavaScript/React/Python] bringe ich eine starke Lernbereitschaft und erste praktische Projekterfahrung mit.

In meinen persönlichen Projekten habe ich [kurz: was du gebaut hast] umgesetzt. Meinen Code finden Sie auf GitHub: [github.com/deinname]

Ich freue mich auf ein Gespräch und stehe ab sofort zur Verfügung.

Mit freundlichen Grüßen
[Dein Name]
[Telefon] | [E-Mail] | [LinkedIn]

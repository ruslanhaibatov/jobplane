# jobplane

ein strukturierter 7-tage-action-plan für junior developer in deutschland. dieses repository hilft dabei, die erste entwicklerstelle zu finden, bewerbungsunterlagen vorzubereiten und sich optimal auf interviews sowie den berufseinstieg vorzubereiten.

## 📋 über das projekt

der einstieg in die softwareentwicklung kann schwierig sein. jobplane bietet einen klaren fahrplan mit täglichen aufgaben, bewerbungsvorlagen, plattformen und tipps, um innerhalb von 7 tagen die ersten bewerbungen zu versenden und intervieweinladungen zu erhalten.

🛠️ tools & plattformen

jobsuche

* linkedin jobs
* stepstone
* indeed
* startup.jobs

portfolio

* github
* github pages
* vercel

bewerbungen

* europass
* canva
* linkedin
* xing

📧 enthaltene vorlagen

* bewerbungs-e-mail (deutsch)
* application e-mail (english)
* linkedin cold message
* persönlicher pitch
* bewerbungstracker

🎯 ziel

innerhalb von 7 tagen:

* professionelle bewerbungsunterlagen erstellen
* github portfolio aufbauen
* 20–30 bewerbungen versenden
* erste intervieweinladungen erhalten

🤝 beitrag leisten

verbesserungsvorschläge, neue ressourcen oder erfahrungen aus dem berufseinstieg sind willkommen.

1. repository forken
2. feature branch erstellen
3. änderungen committen
4. pull request öffnen
